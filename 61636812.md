# Отчет по факту маркировки товаров на складе

## Назначение и описание

Сообщение передается из WMS в ERP после завершения операции маркировки товаров на складе.

Отчет содержит информацию о документе маркировки, перечне промаркированных товаров, кодах маркировки, транспортных упаковках, причинах блокировки и итоговых показателях обработки документа.

Во всех случаях передачи данных в сообщении содержится полный результат обработки документа маркировки.

| 3 | Barcode | Штрихкод товара | 0..1 | String | |

| 3 | Quantity | Количество | 1..1 | Decimal | |
